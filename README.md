This repo contains the official Tigrinya Named Entity Recognition Corpus 2024 (TiNC24), and the tagging guidelines for the dataset.

The TiC03 - MK1 dataset has 155K tokens while the TiC03 - MK2 dataset has over 200K tokens.

For more information on the NER system for Tigrinya language you can check our paper Towards neural named entity recognition system in Tigrinya with large-scale dataset by clicking on https://rdcu.be/eqCpn or cite it by https://doi.org/10.1007/s10579-025-09825-4, which was published on Language Resources and Evaluation (2025) with Springer Nature.


The TiNC24 dataset is copyrighted and should be used only for educational purposes.
